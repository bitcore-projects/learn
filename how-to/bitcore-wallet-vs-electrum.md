> **Short answer:** Both are desktop Bitcoin wallets; compare setup, multisig and interface to decide which suits you.

---

## You'll see this if
- You used Electrum before
- You want a different interface
- You compare features

## Why it happens
Each wallet makes different design choices; the right one depends on your workflow. For background, read the [Bitcore Wallet vs Electrum](https://bitcorewallet.org/vs/electrum) on the Bitcore Wallet website, or the related guide [What happened to Copay and what to do with old wallets](./copay-wallet-history.md).

## How to fix it
1. List features you use daily.
2. Read the side-by-side comparison.
3. Install Bitcore Wallet next to your current wallet.
4. Try a small transaction.
5. Move funds if it fits.

## If that didn't work
If you stay with Electrum, that is fine; keep backups for both. You can also check [download](https://bitcorewallet.org/download) and [Bitcore, Bitcoin Core and BTX: avoiding name confusion](./bitcore-vs-bitcoin-core.md).

## Prevention
Never import the same phrase into unverified apps. The [best desktop wallet](https://bitcorewallet.org/guides/best-desktop-bitcoin-wallet) has more detail.

> [!WARNING]
> Never type your recovery phrase into a website, chat or form. Bitcore Wallet support will never ask for it.

## FAQ
**Can I use both?**  
Yes, with separate wallets.

**Is migration hard?**  
You send coins to a new address.
