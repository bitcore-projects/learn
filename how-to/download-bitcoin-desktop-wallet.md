> **Short answer:** Download Bitcore Wallet only from the tagged GitHub Release or bitcorewallet.org, check the SHA-256 value, then install.

## You'll see this if
- You searched for a Bitcoin wallet download and got several look-alike sites
- An ad offered a 'Bitcore Wallet' installer that is not on GitHub
- You are not sure which file belongs to your operating system

## Why it happens
Wallet downloads are a favourite target for impersonators because one fake installer can empty every wallet it touches. Search ads, cloned pages and file mirrors all look convincing, so the source of the file matters more than how professional the page looks. For background, read the [official Bitcore Wallet download page](https://bitcorewallet.org/download) on the Bitcore Wallet website, or the related guide [How to install Bitcore Wallet on Linux](./install-bitcoin-wallet-linux.md).

## How to fix it
1. Open the official release page directly instead of clicking a search ad.
2. Pick the file for your system: EXE for Windows, DMG for macOS, ZIP for Linux.
3. Compare the file's SHA-256 value with the value published on the release page.
4. Install or unzip the file, launch Bitcore Wallet and create a new wallet.
5. Write your recovery phrase on paper before you receive any bitcoin.

## If that didn't work
If the checksum does not match, delete the file, clear your browser downloads and fetch it again from the release page. A second mismatch means you should stop and report it on the official repository. You can also check [how to spot fake wallet apps](https://bitcorewallet.org/guides/fake-wallet-apps) and [How to back up your Bitcoin recovery phrase](./seed-phrase-backup.md).

## Prevention
Bookmark the official release page and the website download page, and always start from those bookmarks. The [Bitcore Wallet security overview](https://bitcorewallet.org/security) has more detail.

> [!WARNING]
> Never type your recovery phrase into a website, chat or form. Bitcore Wallet support will never ask for it.

## FAQ
**Is Bitcore Wallet free?**  
Yes, it is free to install. You only pay normal Bitcoin network fees when you send.

**Do I need an account?**  
No. The wallet runs on your computer and you hold the keys.
